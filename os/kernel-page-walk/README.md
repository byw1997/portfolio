# ページテーブルの探索（Linuxカーネルモジュール）

システムプログラミング（2023年秋）課題2。C。Ubuntu 22.04.3 LTS（64bit）。

## 内容

10秒ごとに、最も新しく起動したユーザープロセスのメモリ配置を記録し、`/proc/hw2` から読めるようにした（[hw2.c](hw2.c)）。

- **周期実行**：カーネルタイマーで10秒ごとにタスクレットを起動する。
- **対象の選択**：`for_each_process` で全タスクを調べ、カーネルスレッドを除いて開始時刻が最も新しいタスクを選ぶ。
- **ページテーブルの探索**：コード領域の開始・終了の仮想アドレスについて、`pgd_offset` → `p4d_offset` → `pud_offset` → `pmd_offset` → `pte_offset_map` と5段のページテーブルをたどり、各段のエントリと物理ページを求める。データ・ヒープ・スタック領域についても仮想アドレスと物理アドレスを記録する。
- **保持と表示**：直近5回分をスピンロックで守った配列に保持し、`seq_file` で表示する。

## 検証

表示した仮想アドレスの範囲を `/proc/<pid>/maps` の内容と照らし合わせて確認した。

## 動かし方

```
make
sudo insmod hw2.ko
cat /proc/hw2
```
