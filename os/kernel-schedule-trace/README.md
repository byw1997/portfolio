# スケジューラの追跡（Linuxカーネル）

システムプログラミング（2023年秋）課題1。C。Ubuntu 22.04.3 LTS（64bit）。

## 内容

CPUごとのコンテキストスイッチを記録し、`/proc/hw1` から読めるようにした。

1. **カーネルの改変**：`kernel/sched/core.c` の `__schedule()` で、`pick_next_task()` の直後に、切り替え前後のタスクとCPU番号を長さ20の配列に記録する処理を追加し、カーネルを再ビルドした。配列は `EXPORT_SYMBOL` でモジュールから参照できるようにした。追加部分は [kernel-patch/](kernel-patch/) にある。
2. **カーネルモジュール**（[hw1.c](hw1.c)）：`seq_file` で `/proc/hw1` を作り、直近20回の切り替えについて、CPU番号と、切り替え前後のタスクのコマンド名・PID・優先度・開始時刻・スケジューラ種別（CFS, RT, IDLE など）を表示する。

## 動かし方

改変したカーネルで起動した環境で、

```
make
sudo insmod hw1.ko
cat /proc/hw1
```

## 限界

記録用の配列はロックなしで書き換えているため、読み出し中に内容が更新されることがある。
