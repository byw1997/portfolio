# CUDAによるVGG16推論

Multi-core GPU Programming（2024年春）課題6。CUDA。

## 方法

VGG16 の推論に使う次の6種類のカーネルを実装した。いずれも1スレッドが出力の1要素を担当する単純な並列化で、ブロックサイズは128。

| カーネル | 処理 |
| --- | --- |
| normalize | 画素値（0〜255）を [-1, 1] に正規化 |
| pad | 外周に0を埋める |
| conv | 出力の1要素ごとに、入力チャネルとカーネルの積和にバイアスを足す |
| relu | 負の値を0にする |
| pool | 2×2の最大値プーリング |
| fc | 全結合層 |

## 測定

`make` で10回実行し、平均193.0 ms（192.3〜193.9 ms）。

## 備考

共有メモリやタイル化は使っていない。ソースコードはこのリポジトリにまだ収録していない。
