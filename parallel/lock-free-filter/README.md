# ロックを使わない並列フィルタ

Multi-core GPU Programming（2024年春）課題1。C++、std::thread。

## 方法

長さ5のフィルタを配列にかける処理を、ロックを使わずに並列化した。

- 出力配列を15個の区間に分け、スレッドごとに1区間を担当させる（最後のスレッドは残りの要素まで担当）。
- 各スレッドは担当する出力要素の値を最後まで計算してから、1回だけ書き込む。
- 出力の各要素を書くのは1つのスレッドだけで、他のスレッドはその要素を読みも書きもしない。そのため、ロックもキャッシュコヒーレンスへの配慮も要らない。
- 全スレッドを `join()` で待って終了する。

## 測定

`make` で10回実行し、ロックを使う版と比べた。全テストに合格した。

| 版 | 平均 | 中央値 |
| --- | --- | --- |
| ロックなし（自分の実装） | 0.511 | 0.506 |
| ロックあり | 1.165 | 1.164 |

ロックを使わない設計で、2倍強速くなった。単位はレポートに記載していない。
