# OpenMPによる行列積

Multi-core GPU Programming（2024年春）課題3。C++、OpenMP。

## 方法

- **転置**：行列Bを転置してからかけることで、Bを列方向ではなく行方向に読むようにし、キャッシュミスを減らした。転置自体も `collapse(2)` で並列化した。
- **ブロック分割**：ブロックサイズ64で分割し、扱うデータがL1キャッシュに収まるようにした。
- **collapse**：外側2重ループを `collapse(2)` でまとめ、スレッドへの仕事の割り振りを細かくした。
- **一時変数**：ブロック内の部分和を一時変数にためてから結果行列に足し、結果行列への書き込み回数を減らした。
- Strassen法は、計算量の定数が大きく、対象のサイズ（256〜2048）では素朴な方法より遅くなると考えて使わなかった。

## 測定

1024×1024の行列、32スレッド、各条件10回の平均。

| 比較対象 | 自分の実装の速さ |
| --- | --- |
| 逐次の素朴な行列積 | 約472倍 |
| 一時変数を使わず結果行列に直接足す版 | 約3倍 |
| collapse を使わない版 | 約1.3倍 |
