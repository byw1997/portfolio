# UDP上の信頼性のあるファイル転送とP2Pチャット

コンピュータネットワーク（2023年秋）プロジェクト。Python 3.12、Windows 11。

## 内容

- **ARPスキャン**（`pj_1.py`）：指定した範囲のIPアドレスにARPを送り、同じネットワーク内の端末を探す。
- **TCP/UDPでのチャットとファイル転送**（`pj_2.py`）：TCPではそのまま送る。UDPでは信頼性を自分で実装した。
- GUI（`main.py`、`operation.py`）と一部の骨組みは課題で配布されたもので、`todo` となっていた箇所を実装した。

## UDPの信頼性

- パケットに種別・シーケンス番号（16bit、一周したら0に戻る）・データ長を付ける。
- 送信側は送ったパケットと送信時刻を記録し、ウィンドウ（100パケット）に空きがある間は続けて送る。
- 受信側は受け取ったパケットごとにACKを返し、順番が飛んだパケットはバッファにためて、連続した分だけファイルに書き出す。
- 送信側は、ウィンドウ先頭のパケットが5秒以内にACKされなければ、そのパケットだけを送り直す（Selective Repeat）。ACKが連続して揃ったらウィンドウを進める。
