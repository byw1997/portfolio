# 認証付き暗号化ツール（Rust）

情報保護（2024年春）課題3。Rust、openssl・hmac・sha2 クレート。

## 内容

ファイルを暗号化・復号するコマンドラインツール。

```
cryp enc -key <鍵ファイル> -in <入力> -out <出力> -tag <タグ>
cryp dec -key <鍵ファイル> -in <入力> -out <出力> -tag <タグ>
```

- 暗号化：AES-256-CBC で暗号化し、暗号文に対する HMAC-SHA256 をタグとして別ファイルに書く。鍵は32バイトになるよう0で埋めるか切り詰める。
- 復号：先にタグを検証し、一致したときだけ復号する。
- 終了コード：成功は0、タグの検証失敗は1（`VERIFICATION FAILURE`）、引数の誤りは2（`ERROR`）。

## 限界

IVは課題の指定どおり固定値で、暗号化と認証に同じ鍵を使っている。実際の用途では、IVを毎回ランダムにし、鍵を分けるべきである。
