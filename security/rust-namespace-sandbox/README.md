# namespaceによるサンドボックス（Rust）

情報保護（2024年春）課題4。Rust、nix クレート。

## 内容

信頼できない画像分類ライブラリ（darknet の共有ライブラリ、課題で配布）を、ユーザーごとに隔離して実行するプログラム。

1. `requests.txt` から「ユーザー名:画像ファイル:top-k」の要求を読む。
2. 要求ごとに `clone()` で子プロセスを作り、mount・UTS・IPC・network の namespace を分ける。
3. 子プロセスでは、ホスト名をユーザー名にし、ユーザー用ディレクトリ `data/<user>` をbind・読み取り専用・実行不可などのフラグを指定して `/` にマウントしてから分類を実行する。他のユーザーのファイルやネットワークに触れられないようにすることが目的である。
4. 結果は `results.txt` に書き、コピーした重みファイルなどを消して終了する。

## 備考

`unshare()` と `mount()` に root 権限が必要なため、手元の環境では sudo で実行した。ビルドには課題で配布された darknet のバインディング（`../darknet`）が必要で、このリポジトリには含めていない。
